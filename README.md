# human

A Claude skill that keeps writing from sounding AI-generated. It bans the overused words, phrases and structural patterns (English and Arabic) that readers now recognise as machine-written, and tells Claude to rewrite them plainly.

## Install

Put `SKILL.md` in a folder named `human` inside your skills directory, or upload it as a custom skill in Claude settings.

## What it covers

- Overused words (delve, tapestry, realm, leverage, and similar) with plain replacements
- Overused phrases and openers/closers
- Arabic equivalents of common AI phrasing
- Structural tells: "it's not X, it's Y", rule of three, flourish closers, em-dash overuse, over-hedging

## Notes

No single word proves a text is AI-written. The skill targets accumulation of these patterns and the lack of concrete detail.
